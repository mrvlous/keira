# SHA-256 & HMAC-SHA-256

Documentation for SHA-256 digest hashing in [`crates/crypto/src/hash/sha256.rs`](../../../crates/crypto/src/hash/sha256.rs).

## Specifications
- **FIPS 180-4 SHA-256**: Produces a 256-bit (32-byte) message digest using 64-round message scheduling and 8 state variables.
- **RFC 2104 HMAC-SHA-256**: Keyed-Hash Message Authentication Code utilizing inner (`0x36`) and outer (`0x5c`) key padding.

Used extensively by TLS 1.3 key derivation (`HKDF-Extract`, `HKDF-Expand-Label`).
