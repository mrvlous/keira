# Curve25519 (X25519) Key Exchange

Documentation for Elliptic Curve Diffie-Hellman in [`crates/crypto/src/curve/curve25519.rs`](../../../crates/crypto/src/curve/curve25519.rs).

## Specifications
- **RFC 7748 X25519**: Uses the Montgomery curve $y^2 = x^3 + 486662x^2 + x$ over prime field $2^{255} - 19$.
- Implements Montgomery ladder scalar multiplication using constant-time conditional swaps (`cswap`) to prevent timing side-channel attacks.
