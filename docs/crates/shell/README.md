# `keira-shell` - Interactive Shell, Editor & Commands

The `keira-shell` crate implements 75 concrete native shell commands across 7 domain modules, fullscreen modal text editor, tab auto-completion engine, command history buffer, argument parsing (`CliArgs`), and command execution dispatcher.

## Submodules

- [`commands.md`](commands.md): Complete catalog of 75 native shell commands organized across 7 categories.
- [`editor.md`](editor.md): Fullscreen interactive text editor.
- [`autocomplete.md`](autocomplete.md): Tab auto-completion engine.
- [`history.md`](history.md): Command history buffer and navigation.
- [`executor.md`](executor.md): Parsing and command dispatching.
- [`service.md`](service.md): Background system daemons and service controller.
