# `keira-shell` - Interactive Shell, Editor & Commands

The `keira-shell` crate implements the 74 concrete native shell commands, fullscreen `kvi` text editor, tab auto-completion engine, command history buffer, argument parsing, and command execution.

## Submodules

- [`commands.md`](commands.md): Complete catalog of 74 native shell commands.
- [`editor.md`](editor.md): Fullscreen interactive `kvi` text editor.
- [`autocomplete.md`](autocomplete.md): Tab auto-completion engine.
- [`history.md`](history.md): Command history buffer and navigation.
- [`executor.md`](executor.md): Parsing and command dispatching.
