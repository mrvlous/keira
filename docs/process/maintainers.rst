Keira Kernel Maintainers & Subsystem Map
========================================

The Keira Kernel project uses a subsystem maintainer model modeled directly after the Linux Kernel MAINTAINERS specification. Each architectural area and crate is overseen by designated subsystem maintainers responsible for reviewing patches, verifying hardware safety and approving pull requests.
