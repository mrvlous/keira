# SHA-256 Cryptographic Hash Function

Implements FIPS 180-4 secure hash algorithm producing a 256-bit digest (`crates/crypto/src/hash/`).

---

## 1. Mathematical Round Functions

For each 64-byte block across 64 compression iterations:
$$\Sigma_0(x) = \text{ROTR}^2(x) \oplus \text{ROTR}^{13}(x) \oplus \text{ROTR}^{22}(x)$$
$$\Sigma_1(x) = \text{ROTR}^6(x) \oplus \text{ROTR}^{11}(x) \oplus \text{ROTR}^{25}(x)$$
$$\sigma_0(x) = \text{ROTR}^7(x) \oplus \text{ROTR}^{18}(x) \oplus \text{SHR}^3(x)$$
$$\sigma_1(x) = \text{ROTR}^{17}(x) \oplus \text{ROTR}^{19}(x) \oplus \text{SHR}^{10}(x)$$
$$\text{Ch}(x, y, z) = (x \land y) \oplus (\neg x \land z)$$
$$\text{Maj}(x, y, z) = (x \land y) \oplus (x \land z) \oplus (y \land z)$$

---

## 2. Usage in Keira

* **Disk Integrity Verification**: Validates sha256 checksums of system modules and binaries during boot.
* **TLS 1.3 Key Derivation**: HKDF-Extract and HKDF-Expand primitives depend on SHA-256 for session keys.
* **TPM 2.0 PCR Extension**: Extends software measurements into hardware PCR registers.
