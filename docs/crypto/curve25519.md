# Curve25519 (X25519) Key Exchange

This document specifies Montgomery curve scalar multiplication for Diffie-Hellman key agreement in Keira Kernel.

---

## Technical Specifications

* **Curve Equation**: $y^2 = x^3 + 486662x^2 + x$ over prime field $2^{255} - 19$.
* **Key Length**: 256 bits (32 bytes).

---

## Core API (`crates/crypto/src/curve25519.rs`)

```rust
pub fn x25519_scalarmult(scalar: &[u8; 32], point: &[u8; 32]) -> [u8; 32];
pub fn generate_keypair() -> ([u8; 32], [u8; 32]);
```
