# SHA-256 & HMAC Cryptographic Primitives

This document specifies the bare-metal SHA-256 hash function and HMAC engine in Keira Kernel.

---

## Technical Specifications

* **Digest Size**: 256 bits (32 bytes).
* **Block Size**: 512 bits (64 bytes).
* **Endianness**: Big-endian word manipulation.

---

## Core API (`crates/crypto/src/sha256.rs`)

```rust
pub fn sha256(data: &[u8]) -> [u8; 32];
pub fn hmac_sha256(key: &[u8], data: &[u8]) -> [u8; 32];
```
