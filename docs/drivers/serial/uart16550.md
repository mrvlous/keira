# 16550 UART COM1 Serial Interface Driver

This document details the 16550 Universal Asynchronous Receiver-Transmitter (UART) serial controller driver in Keira Kernel.

---

## Technical Specifications

* **Base Port**: `0x3F8` (`COM1`).
* **Registers**:
  * `0x3F8`: Receiver Buffer (R) / Transmitter Holding (W) / Divisor Latch Low (DLAB=1).
  * `0x3F9`: Interrupt Enable Register (IER) / Divisor Latch High (DLAB=1).
  * `0x3FA`: Interrupt Identification Register (IIR) / FIFO Control (FCR).
  * `0x3FB`: Line Control Register (LCR).
  * `0x3FC`: Modem Control Register (MCR).
  * `0x3FD`: Line Status Register (LSR).
* **Baud Rate**: 115,200 baud (Divisor `0x0001`).
* **Protocol Framing**: 8 data bits, no parity, 1 stop bit (`8-N-1`).

---

## Initialization Sequence (`crates/io/src/serial/mod.rs`)

```rust
pub unsafe fn init() {
    outb(0x3F8 + 1, 0x00); // Disable all UART interrupts
    outb(0x3F8 + 3, 0x80); // Enable DLAB (set baud rate divisor)
    outb(0x3F8 + 0, 0x01); // Set divisor to 1 (lo byte) -> 115200 baud
    outb(0x3F8 + 1, 0x00); //                  (hi byte)
    outb(0x3F8 + 3, 0x03); // 8 bits, no parity, one stop bit (8-N-1)
    outb(0x3F8 + 2, 0xC7); // Enable FIFO, clear them, with 14-byte threshold
    outb(0x3F8 + 4, 0x0B); // IRQs enabled, RTS/DSR set
}
```
