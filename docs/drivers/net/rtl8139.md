# Realtek RTL8139 Fast Ethernet Driver

This document details the Realtek RTL8139 Fast Ethernet PCI network driver in Keira Kernel.

---

## Technical Specifications

* **PCI IDs**: Vendor `0x10EC`, Device `0x8139`.
* **RX Ring**: 8KB + 16-byte continuous circular ring buffer with wrap-around padding.
* **TX Descriptors**: 4 independent transmit start address registers (`TSAD0`–`TSAD3`).

---

## Core API (`crates/net/src/drivers/rtl8139.rs`)

```rust
pub unsafe fn init(io_base: u16) -> Result<(), &'static str>;
pub unsafe fn transmit(packet: &[u8]) -> Result<(), &'static str>;
pub unsafe fn receive(buf: &mut [u8]) -> Result<usize, &'static str>;
```
