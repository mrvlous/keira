# Intel 82540EM (e1000) Gigabit Ethernet Driver

This document specifies the bare-metal driver for the Intel 82540EM/82545EM Gigabit Ethernet controller, managing circular DMA ring descriptors and raw frame processing in Keira Kernel.

---

## E1000 DMA Ring Architecture

```mermaid
graph LR
    subgraph RX Ring (32 Descriptors)
        RX0["Desc 0 (2KB Buffer)"] --> RX1["Desc 1 (2KB Buffer)"]
        RX1 --> RX_N["..."]
        RX_N --> RX0
    end
    subgraph TX Ring (8 Descriptors)
        TX0["Desc 0 (Packet Ptr)"] --> TX1["Desc 1 (Packet Ptr)"]
        TX1 --> TX_N["..."]
        TX_N --> TX0
    end
```

---

## Technical Specifications

| Parameter | Specification | Description |
| :--- | :--- | :--- |
| **PCI Identifiers** | Vendor `0x8086`, Device `0x100E` | Intel PRO/1000 MT Desktop Adapter |
| **RX Ring Size** | 32 Descriptors | 2048-byte receive packet buffers per descriptor |
| **TX Ring Size** | 8 Descriptors | Asynchronous transmit buffer descriptor chain |
| **Interrupt Mask** | ICR / IMS Registers | `RXT0` (Receive Timer) and `TXDW` (Transmit Descriptor Written) |

## Core API (`crates/net/src/driver/e1000.rs`)

```rust
/// Probe PCI bus, map MMIO/IO registers, initialize RX/TX rings, and enable NIC.
pub unsafe fn init() -> Result<(), &'static str>;

/// Transmit a raw Ethernet frame over the physical wire via TX ring.
pub unsafe fn transmit_raw_frame(frame: &[u8]) -> Result<(), &'static str>;

/// Receive an incoming raw Ethernet frame from the circular RX ring.
pub unsafe fn receive_raw_frame(buf: &mut [u8]) -> Result<usize, &'static str>;
```
