# Intel 82540EM Gigabit Ethernet Driver (`e1000`)

This document details the Intel e1000 Gigabit Ethernet network adapter driver in Keira Kernel.

---

## Technical Specifications

* **PCI IDs**: Vendor `0x8086`, Device `0x100E` (82540EM) / `0x10D3` (82574L).
* **Ring Buffers**: Circular Receive (RX) and Transmit (TX) descriptor rings (32 descriptors each).
* **DMA Alignment**: 16-byte aligned hardware descriptor rings in contiguous physical memory.

---

## Core API (`crates/net/src/drivers/e1000.rs`)

```rust
pub unsafe fn init(bar0: usize) -> Result<(), &'static str>;
pub unsafe fn transmit_packet(packet: &[u8]) -> Result<(), &'static str>;
pub unsafe fn poll_receive(buf: &mut [u8]) -> Result<usize, &'static str>;
```
