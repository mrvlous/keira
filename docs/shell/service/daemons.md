# Standard Background Services

* `syslogd`: Kernel diagnostic audit logger.
* `syncd`: Periodic FAT16 dirty sector flushing.
* `watchdogd`: Health monitoring and task hang detection.
* `timed`: CMOS RTC clock synchronization.
* `monitord`: System telemetry and memory health inspector.
* `netd`: Network ARP cache and link state monitor.
